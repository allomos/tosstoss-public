**Outcome.** 投桃（Tosstoss）是一个在同一局域网内传递文件的 Web 应用。在局域网内的一台电脑上启动它的服务器后，同一局域网内任何人用浏览器（电脑或手机）打开它的网址，就会自动互相发现；用户勾选一个或多个对方，选择或拖放文件，点击发送，对方自动接收。

**谁来用。** 同一个局域网（家里、办公室）里想快速互传文件的人，用电脑或手机浏览器。

**验收标准**（每条都可以亲手试）：
1. 在一台电脑上运行 `npm install && npm start`，终端打印出局域网网址（如 `http://192.168.x.x:8080`）。
2. 两台以上设备（含至少一部手机）打开该网址，几秒内各自的页面上都出现其他在线设备，各有名字；新打开或关闭网页时，列表自动更新。
3. 用户 A 勾选 B 和 C，从本地选择文件或把文件拖放到页面的文件框区域，点击“发送”，B 和 C 不做任何操作就收到文件，并能保存/打开，内容与原文件一致。
4. 自动接收是默认且不可更改的：界面上没有关闭自动接收的选项。
5. 点击“下线”后，该用户从其他人的列表中消失，也不再收到文件；点击“上线”后重新出现。关闭网页效果相同。
6. 页面标题和界面显示“投桃 Tosstoss”；在手机浏览器（窄屏、触屏）上可以完整完成勾选、选择文件、发送和接收。
7. 发送时双方都能看到进度；一次可发多个文件；几百 MB 的文件也能传完。
