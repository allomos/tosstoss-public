**结果.** 公网版“谁能看到我”改为三选一：**局域网内公开**（原“对网络公开”，默认）/ **广场** / **下线**；去掉“隐身”。选“广场”后，所有选了广场的设备不论在哪个网络都互相可见，可以互发文件。

**完成标准.**
- 两台不同网络（不同公网 IP）的设备都选“广场”后互相看到，能传文件。
- 广场里收到文件先询问：接收方点“接收”才开始传，点“拒绝”或 60 秒不理则不传，发送方看到原因。服务器在对方接收前不转发任何文件内容。
- 广场里不直连（不暴露 IP），都经服务器；每个文件最大 20 MB（不限大小版也一样）。
- 一个广场最多 200 人，满了自动进入下一个广场分片。每台设备每分钟最多发起 20 个文件。
- 选择刷新后保留；房间内不受影响；局域网 npm start 版只有“在线 / 下线”。
- `npm test` 与 `npm run test:cf` 通过。
