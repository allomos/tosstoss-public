# Handoff: claude-plaza (A02-06 广场)

**State.** Done and verified locally, on branch `claude/plaza` (commit 5aaad17), pushed. Not merged into main, not deployed. Waiting on the person to approve the merge and deploy.

**What changed.** On the internet version, "谁能看到我" now offers 局域网内公开 (the default) / 广场 / 下线. 隐身 is gone. The plaza runs in worker/index.js: `?plaza=1` puts a device on the Hub `plaza:N`, which holds 200 at most. Offers must be answered with `file-answer`. Signals are dropped. Files are capped at 20 MB, and each device may offer at most 20 per minute. A setTimeout keeps the Hub awake while an offer waits for an answer, and the Hub withdraws the offer after 65 s. On the page: transfer.js handles the asking / waiting state and the 接收 / 拒绝 buttons. app.js stores the choice in localStorage `tosstoss.place`.

**Checked.** `npm test` passes. `npm run test:cf` passes against both dev:cf and dev:cf:unlimited (16 pass, 1 skipped). The new test "quiet wait" fails when the keep-awake timer is removed. In the browser preview, with two origins both in the plaza: accepting after a 15 s wait delivered the file intact, 拒绝 showed "对方没有接收" to the sender, and switching back to 局域网内公开 took the device out of the plaza.

**Next.** Once the person approves: `git switch main && git merge claude/plaza && git push`, then `npm run deploy` and `npm run deploy:unlimited`. Then the person tries it on two real devices on different networks.
