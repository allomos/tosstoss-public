# 投桃 Tosstoss

局域网内互传文件的 Web 应用。同一局域网里打开这个网页的设备会自动互相发现；勾选对方、选择或拖放文件、点“发送”，对方自动接收。电脑和手机浏览器都能用。

## 启动

需要 Node.js 18 或更新版本。在局域网内的一台电脑上：

```bash
npm install
npm start
```

终端会打印网址，例如 `http://192.168.1.202:8080`。在同一局域网的其他电脑或手机浏览器中打开它。端口可用 `PORT=9000 npm start` 修改。

## 使用

- **在线设备**：所有打开该网址的设备会自动出现在列表中，带名字和电脑/手机图标。点一下即可勾选。点自己名字旁的 ✎ 可以改名。
- **发送**：点击文件框选择文件，或把文件拖到页面上（也可以粘贴），然后点“发送给 N 台设备”。
- **进度**：发送和接收都显示进度；多个文件依次发送；大文件也能传（发送端按接收端的回执控制速度）。
- **自动接收**：别人发来的文件会直接收下并自动下载，无法关闭；“传输记录”里也可以再点“保存”（手机浏览器常拦截自动下载，这时点“保存”）。
- **下线**：在“我的设备”下面选“下线”，别人就看不到你，也无法给你发文件；页面只留“我的设备”和“你现在已下线”，传输记录保留；选“在线”恢复。关闭网页效果相同。

## 已知限制

- 手机锁屏或切到后台时连接会断开，正在进行的传输会失败，需要重发；回到页面后会自动重新上线。
- 收到的文件先放在浏览器里，几 GB 的文件在手机上可能放不下。

## 工作方式

浏览器无法自行在局域网里广播，所以运行 `npm start` 的那台电脑充当会合点：网页通过 WebSocket 连到它，它维护在线列表，并把文件分块中转给勾选的接收方。文件不会保存在服务器上。

**直连优先**：点“发送”后，浏览器先尝试和接收方建立 WebRTC 直连（服务器只转发几 KB 的连接信息）。连上了，文件就在两台设备之间直接传：同一 Wi-Fi 下走局域网，不经过服务器，也不消耗 Cloudflare 额度。5 秒内连不上（比如某些公司网络），自动改走服务器中转，之后 1 分钟内发给这台设备都直接中转。传输记录里会标出“直连”或“经服务器”。直连时双方能看到彼此的 IP 地址。

## 部署到 Cloudflare（公网版）

公网版跑在 Cloudflare Workers 上：网页由 Workers Assets 提供，在线列表和分块中转由 Durable Object（`worker/index.js`）负责，免费套餐即可。

```bash
npx wrangler login         # 第一次：登录自己的 Cloudflare 账号
npm run deploy             # 公开版：经服务器中转的文件每个最大 20 MB（直连不限）
npm run deploy:unlimited   # 不限大小版：名字难猜的专用网址
```

同一份代码发布成两个版本（在 `wrangler.jsonc` 里）：公开版 `tosstoss` 经服务器中转的文件每个最多 20 MB（服务器也会拦截），直连的文件不限大小；`unlimited` 环境用一个难猜的名字，不限文件大小，只靠网址不外传来保密。两个版本共用同一个账号的免费额度。

不限大小版的真实名字不进 Git：`wrangler.jsonc` 里只有占位符 `__UNLIMITED_WORKER_NAME__`，`npm run deploy:unlimited`（`scripts/unlimited.js`）发布时从环境变量 `TOSSTOSS_UNLIMITED_NAME` 或被 Git 忽略的文件 `.unlimited-name` 读出真实名字再替换进去。第一次先生成一个：

```bash
node scripts/unlimited.js new-name > .unlimited-name
```

公网版和局域网版的区别：

- **谁能看到我**：“我的设备”下面四选一。**局域网公开**（默认）：使用同一公网 IP（通常是同一 Wi-Fi）的设备都能看到你、给你发文件。**广场**：所有选了广场的设备都能互相看到，不论在哪个网络；别人发来的文件要你点“接收”才开始传（60 秒不理就作废），广场里不直连（不暴露 IP），都经服务器中转，每个文件最大 20 MB，每台设备每分钟最多发 20 个文件；一个广场最多 200 人，满了自动进下一个。**房间**：见下。**下线**：断开，什么都收发不了。选择会记住，刷新后不变。局域网版只有“在线 / 下线”。
- **房间**：选“房间”就回到上次的房间（没有就新建一个），下面显示房间码、复制链接、显示二维码、加入其他房间、重建房间（换一个新房间码，旧房间里的设备不再看到你）。打开链接或输入房间码的设备在同一房间里互相可见，不论在哪个网络（手机流量也行）；打开房间链接会直接进入“房间”。切到别的选项就离开房间。
- 文件经 Cloudflare 中转，不落盘。

本地试公网版：`npm run dev:cf`（20 MB 限制）或 `npm run dev:cf:unlimited`（http://127.0.0.1:8787），再用 `npm run test:cf` 对它跑全部测试。
